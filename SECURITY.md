# Security Policy & Vulnerability Disclosure

## 🛡️ Commitment to Information Security
AILeash is dedicated to providing deterministic, tamper-evident governance infrastructure. We maintain rigorous standards to ensure the cryptographic integrity of our SHA-256 audit chains and the resilience of our 9-signal scoring engine.

## 📦 Supported Versions
Security updates and patches are actively applied to the following production horizons:


| Version | Supported | Notes |
| :--- | :---: | :--- |
| v2.1.x |  ✅ Yes  | Current Production Release (`sebbi.pro`) |
| v2.0.x |  ✅ Yes  | Security Patches Only (Expires Aug 2026) |
| v1.x.x |  ❌ No   | Legacy Node Architecture |

## 🚨 Reporting a Vulnerability
Do not open a public GitHub issue for suspected vulnerabilities. To protect integrated enterprise environments, please report all findings directly through our secure channel:

* **Email**: security@sebbi.pro
* **Encryption**: Please encrypt your payload using our public PGP key if handling sensitive threat details.

### Our Response Protocol
1. **Acknowledgement**: Within 24 hours of receipt.
2. **Triage & Validation**: Comprehensive analysis completed within 72 hours.
