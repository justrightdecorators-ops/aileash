Running it

Python 3.8 or newer. No dependencies to install — it uses only what ships with Python.

  1. Start it

    python3 sebbi_tokensaver.py --key YOUR_KEY --provider anthropic

    No key yet? Use --offline. It saves you exactly the same money; you just do not get receipts.

  2. Change the one line

    base_url = "http://127.0.0.1:8788"   # that is the whole integration

  3. Watch it work

    http://127.0.0.1:8788/saver

    One number: tokens you did not buy, taken from your provider's own reported counts. Never an estimate, never a percentage.

What it does not do

Published here rather than discovered later.

  • Matching is exact. A reworded prompt is a different prompt and goes to your provider. Catching similar prompts needs an embedding, an embedding is a model call, and a model call is the cost we are here to remove.
  • It does not judge whether a stored answer is still correct. It proves what was asked and what came back.
  • Answers to requests with temperature above zero are not stored, because serving one back would change how your system behaves. You can override that deliberately.
  • A refused request has a worst case cost, not a known cost. It is reported apart from your real savings and never added to them.
  • If our platform is unreachable your traffic keeps flowing. It fails open, always. A cost tool that can take your production down is not worth any saving.
