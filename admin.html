Break glass

If the chain ever breaks

This does not repair anything. Repairing a broken chain is the operator rewriting the record — the one thing this whole platform exists to make impossible. What it does instead is capture the break so its exact shape is provable afterwards.

1. freeze — read and pin the current tip
2. locate — walk the links and name the first block whose prev_hash stops matching
3. export — pull every record to this phone as JSON
4. externalise — hand the frozen tip to the witness network so somebody outside holds it
