Technical Brief

What you are actually
selling your clients.

This is not a compliance checkbox. This is cryptographic infrastructure. Here is how to explain it to a CTO or compliance officer in plain English.

The Core Technology

SHA-256 Merkle Audit Chain

Every AI decision is sealed into a cryptographic chain. The same technology that underpins Bitcoin. Each block contains the event, the decision, the timestamp, and the hash of the previous block. Alter any record and the chain breaks. Mathematically impossible to hide tampering. Not a log file. Cryptographic proof.

The Scoring Engine

9-Signal EWMA Weighted Model

Every decision scored across 9 weighted signals simultaneously. Trust score, velocity across 60s, 5m and 1h windows, transaction amount, device risk, anomaly score, country shift, safe country, trust floor. EWMA decay means trust scores evolve across sessions. Sub-1ms decision time locally. Sub-20ms via API.

Data Sovereignty

Runs Inside Your Client Stack

The Sebdog Engine is a single Python file that deploys inside your client's own infrastructure. Their data never leaves their network on the hot path. The audit chain builds in their own database. They own it completely. Licence validates against sebbi.pro on startup and every 24 hours. Everything else is local.

Legal Coverage

Four Regulations. One Engine.

EU AI Act Articles 9, 12, 13 and 14 satisfied from a single API call. Online Safety Act 2023 compliant. ICO Children's Code compliant. Digital Services Act compliant. Every decision comes with a plain-language reasons array. Every block or challenge is explainable to a regulator on demand.

Call Centre Specific

Pre-Call Intelligence

Before the agent picks up, AILeash scores the caller. Device type, location, network provider, how many times they have called in the last 60 seconds, 5 minutes and hour, whether the number has flagged before, device risk score. Agent sees ALLOW, CHALLENGE or BLOCK on their screen before hello. Fraud caught before a word is spoken.

Evidence Chain

Admissible In Court

Every decision is sealed with a SHA-256 hash that references the previous hash back to genesis. Cryptographically verifiable by anyone, anywhere, at any time. If a caller disputes a decision six months later, your client has proof of exactly what the engine knew and decided at the exact millisecond of that interaction.

# AILeash integration — one function, zero dependencies # Get your API key at sebbi.pro — 100 free decisions, no card required import urllib.request, json def govern(event, api_key): req = urllib.request.Request( "https://sebbi.pro/api/govern", data=json.dumps(event).encode(), headers={ "Authorization": f"Bearer {api_key}", "Content-Type": "application/json" }, method="POST" ) with urllib.request.urlopen(req, timeout=5) as r: return json.loads(r.read()) # Call it on every AI decision that affects a user result = govern({ "user_id": "user_123", # your user identifier "action": "loan_decision", # what the AI is deciding "amount": 25000.00, # value involved (0 if none) "country": "GB", # ISO country code "device_id": "device_abc", # device fingerprint "anomaly": 0.1, # your anomaly score 0.0-1.0 "device_risk": 0.05 # your device risk 0.0-1.0 }, "YOUR_API_KEY") # Engine responds in under 20ms print(result["decision"]) # ALLOW / CHALLENGE / BLOCK print(result["score"]) # 0.1842 print(result["reasons"]) # [] or ["velocity_spike", "high_amount"] print(result["audit_hash"]) # a3f9b2c1... sealed in chain forever
