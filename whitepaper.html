Technical Capture: Complete Event Reconstruction

Every decision now includes:

  • Timing phases: Microsecond deltas for auth, signal computation, decision, context extraction, seal
  • Request context: IP, port, protocol, TLS version, TLS cipher, user-agent, accept-language, referer, device fingerprint
  • Signal derivation: Raw values → normalized → weighted contributions to final score
  • Decision trace: Score, decision (ALLOW/CHALLENGE/BLOCK), all reason codes
  • Velocity snapshot: Window sizes (60s, 5m, 1h) at decision time
  • GeoIP context: Country, ASN, city (for routing analysis)
  • Chain continuity: Previous 3 blocks + genesis link (tampering detection)

Guardian: Network Safeguarding

Guardian detects predatory patterns in network traffic. Business/safeguarding teams only — not parental control. Features:

  • Pattern vocabulary: sustained_contact, escalation, isolation tactics
  • Behavioral timeline: temporal sequence of suspicious events
  • Confidence scoring: 0.0–1.0 on detected patterns
  • CEOP/NCA reporting: Evidence package generation (placeholder for API integration)
  • Free for safeguarding teams, permanently
