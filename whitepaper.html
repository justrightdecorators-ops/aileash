Block 001 · The Engine

How it works.

Deterministic weighted scoring across nine signals. No machine learning. No drift. No re-training. Weights are immutable in code.

score = clamp( Σ , 0, 1 ) where Σ =
(1 − trust) × 0.30
+ min(velocity_60s / 20, 1) × 0.15
+ min(velocity_5m / 50, 1) × 0.10
+ min(velocity_1h / 200, 1) × 0.10
+ min(ln(1+amount) / ln(1+10000), 1) × 0.15
+ device_risk × 0.10
+ behavioural_anomaly × 0.10
+ country_shift × 0.10
+ unsafe_country × 0.10

decision = ALLOW if score < 0.35
= CHALLENGE if score < 0.70
= BLOCK otherwise

Trust is per-user and persistent. It takes roughly 70 clean events to climb from neutral to 0.75, and three blocks to fall below it. This asymmetry is institutional memory.

Three velocity windows (60 seconds, 5 minutes, 1 hour) catch the three canonical attack tempos: burst (bot), sustained (scripted abuse), and slow compromise.

Block 002 · The Chain

Tamper-evident record keeping.

Every decision is sealed before the API response returns. The construction is simple: canonical JSON of the previous hash, timestamp, event, and result, hashed with SHA-256.

What the chain proves

A valid chain proves the record has not been altered since genesis: change one character and every subsequent hash breaks, detectably, by anyone recomputing forward. It does not prove the system worked correctly; it proves the system's own word didn't change.

Each block carries the API key that produced it, stored alongside the block, never inside it. When a regulator asks "did you issue this decision?", you can answer with proof that you did, and what it said, and when.

Block 008 · The Thesis

Technical capture as market position.

Lock-in is contractual: exit fees, term commitments, lawyers holding the door. Technical capture is structural: the product's own physics make leaving expensive, with no contractual penalty at all.

Exported records are data; the tamper-evidence regulators demand lives in the unbroken chain, which cannot migrate. Unbroken beats rebuilt, every time a regulator asks the question.

Per-user trust is earned decision-by-decision inside the engine. A departing platform restarts every user at neutral — detection quality drops on day one of the next vendor.

Customer badges are rendered live against account standing. Leaving is publicly visible on your own site — UNVERIFIED, in grey.
