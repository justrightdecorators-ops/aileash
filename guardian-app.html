The Scoring Engine

9-Signal EWMA Model

Guardian uses the same 9-signal weighted engine as AILeash but with child safety signals weighted differently. Trust decay is accelerated for predator patterns. Velocity windows track message frequency. Anomaly scores detect grooming language. CSAM triggers a hard block at any score.

The Audit Chain

SHA-256 Merkle Chain

Every decision sealed with SHA-256. Each block contains the event, the decision, the timestamp, and the hash of the previous block. Alter any record and the chain breaks. Cryptographically impossible to hide. Every block decision generates a structured evidence package ready for CEOP and Action Fraud.
